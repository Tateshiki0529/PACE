# PACE

**Predictive, Adaptive, Cooperative and Evolving Driving Policy**

PACEは、安全で柔軟な運転を実現するための公開安全運転方針です。

特定の車種や安全装備に依存せず、自らが運転するすべての自動車に適用できる方針を目指していきます。

## 基本思想

PACEでは、単に決められた手順を守ることだけを安全運転とは考えません。

道路、交通、車両、運転者の状態を継続的に認識し、十分な余裕を確保しながら、状況の変化に応じて適切な行動を選択することを重視します。

また、自身の安全だけでなく、同乗者や周囲の道路利用者の安全と安心、そして交通の円滑との両立を目指します。

## 名称

PACEは次の4つの考え方を表します。

- Predictive - 予測する
- Adaptive - 適応する
- Cooperative - 協調する
- Evolving - 改善し続ける

「pace」という言葉そのものにも、状況に適したペースで進むという意味を持たせています。

## 文書構成

PACEは、次の階層で構成します。

1. 安全7原則
2. 共通規則
3. 状況規則
4. 附則

法令は、これらすべてより優先されるものとします。

## 開発・改善

PACEは、安全運転のためにいつでも見返せる公開テキストとして作成します。

一度完成して終わるものではなく、運転中の経験・事故・ヒヤリハット事例・新しい安全知見・法令改正・車両技術の進化を受けながら、継続的に見直していきます。

日常の運転で判断に迷ったとき、自分の運転を振り返りたいとき、新しい安全対策を検討するときに、いつでも立ち返れる基準であることを目指します。

PACEはGitHubで管理し、変更履歴を公開します。

改善案・疑問点・問題点・新しい知見などはIssueで広く募集し、具体的な変更案はPull Requestとして提案できます。

提案された変更は、安全性・根拠・法令・安全7原則・既存規則との整合性を確認したうえで採否を判断します。
